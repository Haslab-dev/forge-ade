# FORGE-145 — Native computer-use tools (shipped)

- **Type:** Story · **Priority:** High · **Status:** ✅ Done · **Component:** go/agent, frontend
- **Description:** The ZCode `computer-use` MCP server cannot run inside ForgeADE (needs the ZCode permission-broker socket), leaving the agent with no desktop control. Shipped **own native tools** instead:
  - `internal/computeruse` — CGEvent mouse/keyboard input (cgo CoreGraphics, browseruse shim style), `screencapture` to the project sandbox `tmp/` (auto-pruned), `CGWindowList` window enumeration; TCC Accessibility + Screen Recording checks with actionable errors.
  - Tools: `computer_screenshot` (approval-free), `computer_click/_type/_key/_scroll/_window_list` (gated like mutations — added to `isMutatingTool`, so they pause unless Full access).
  - **Vision enabler:** `messagesToLLM` now attaches `computer_screenshot` results to the model as an `image_url` part (user-role message after the tool result, 4MB cap) — tool results are text-only on OpenAI-compatible APIs, so without this the agent could not see the screen.
  - UI: Settings → Computer Use → "Native computer-use tools" card with live Accessibility/Screen Recording status and a Grant permissions shortcut (`GetComputerUseStatus`/`OpenComputerUsePermissions` bindings).
  - Tests: 8 Go tests (validation, chord parsing, key table, PNG sizing, settings shape).
  - **Follow-up fix (same day):** the JEV tool router silently dropped the new tools — `filterToolsByCategory` has hardcoded per-category allowlists that didn't know `computer_*`, and a "none"/low-confidence classification returned **zero tools** even when the prompt cited a tool by name (user-reported: "there's no computer_screenshot tool in my current toolset" on glm-5-3-flash). Fixed in two layers: (1) `computer_*` added to `UniversalToolNames()` — the always-active coordination set; (2) a "none" classification now returns the **universal set** (+ any explicitly cited tools) instead of `nil` — verified live that a mis-routed turn reached the model with an empty toolset, which then hallucinated a 7-tool Unix toolset ("read/git_diff/grep/ls/bash") from training data. 3 JEV tests added (universal-set membership per category, explicit mentions, none-branch regression).
