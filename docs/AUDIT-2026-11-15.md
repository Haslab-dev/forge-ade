## P0 — crash / security / data loss

1. **ACP permission prompt crashes the app.** `modals.go:489` passes `nil` open pointer to
   `ui.Modal`; mygo dereferences it unconditionally (`widgets.go:660`, `base.go:692`). Verified
   with a scratch repro. Every `session/request_permission` from an ACP agent (`acp.go:873`)
   panics the frame; no `recover()` exists anywhere in the UI layer.
2. **Editor data loss on every close path.** `editor.go:532-545` — `CloseTab` deletes the doc
   unconditionally even when the buffer is modified. ⌘W, tab X, Close Others/All/Left/Right,
   drawer open-files list, and workspace switch all discard unsaved edits with no prompt.
3. **SSH host-key verification disabled.** `core/remotefs/client.go:142` —
   `ssh.InsecureIgnoreHostKey()` ships on main; MITM can capture saved credentials.
4. **Secrets stored plaintext, world-readable.** `ssh_modal.go:156-163` writes
   `ssh_saved_hosts.json` (with `Password`, `KeyPassphrase`) via `os.WriteFile(…, 0644)`;
   provider API keys likewise (RakitKode `provider.go:381`). Every connect silently persists.
5. **Board file wiped on corrupt/mid-write read.** `core/board/manager.go:205,300` ignore JSON
   unmarshal errors then overwrite `board_tasks.json` — all tasks destroyed. Agents edit this
   file non-atomically (the watcher even retries for that reason), so the trigger is realistic.
6. **Confirmed data race in `GitManager` (production render path).** Writers lock
   (`git.go:178`); the 29 UI read sites don't (`header.go:86` via `drawer.go:77`, etc.).
   Triggered by `go initGit.Refresh()` at `app.go:626` racing the first frame — race detector
   reproduces every run. Raced fields are slices → torn slice headers can crash the render loop.
   Root cause of the flaky `pkg/ui` tests.

## P1 — user-visible functional bugs

**Git / source control**
- Porcelain-v2 parser breaks on any filename containing a space (`core/git/status.go:202` —
  `strings.Fields` + fixed index). Stage/unstage/discard/diff operate on truncated phantom
  paths. Extremely common case.
- "Commit" button runs `git add .` + `git status` + `git commit` + 2× refresh sequentially on
  the render thread, up to ~40s freeze (`drawer.go:638-654`); Stage All / Unstage All / refresh
  / branch-switch do the same (`drawer.go:386-524`, `header.go:285`).
- `Refresh()` holds `gm.mu` across a 10s-timeout `git status` (`git.go:154-186`), blocking all
  concurrent GitManager calls and UI readers.
- Background goroutines read `gm.RootDir` unlocked (`git.go:403,534`) — wrong-repo diff/commit
  after fast workspace switch.
- PR detail fetch error → infinite "Loading details" spinner, error swallowed
  (`git_pr_worktrees.go:130-145`); failed diff silently renders nothing.
- Any commit failure triggers `git add -A` + retry (`core/git/status.go:536-545`) — stages
  untracked files the user never selected.
- `GitCheckout`/`GitCreateBranch` don't pass `--` separator (`engine.go:224-241`).

**Agent chat**
- Stop doesn't stop: cancel mid-turn still drains the steer queue and auto-launches the next
  queued prompt (`agent.go:602-671` + `app.go:489-491`).
- Raw-LLM fallback turn can't be cancelled: stream keeps running and appending to a done
  message for up to 2 minutes after Stop — tokens burn (`agent.go:3083-3099`).
- Toasts fired from background goroutines are silently dropped (`AddToast` no-ops outside a
  frame, mygo `frame.go:29-34`): "Checkpoint Restored / Restore Failed / Turn Changes Undone"
  never appear (`agent_view.go:345,1070,2892-2897,3047-3053`).
- Render path reads `as.Messages`/`m.Text` unlocked while streaming goroutines mutate under
  `as.mu` (`agent_view.go:143-197` vs `agent.go:362,333`); `SaveSessionToDisk` iterates
  messages unlocked after callers release the lock (`agent.go:1500-1597`).
- Composer-menu `/clear` is a broken duplicate: clears only `sess.Messages`, never the display
  alias or disk state (`composer_menu.go:311-321`).
- Failed question submit blocks the RakitKode turn forever: pending state cleared before
  responding, response error discarded (`internal_agent.go:425-460`, `agent_view.go:2892,3048`).
- Concurrent map read/write crash window on `QuestionDrafts` (`agent_view.go:2993-2999`).

**Editor / search**
- Clicking search results, "@" hits, F12/peek results does nothing: rg returns absolute paths
  double-prefixed by `ResolveFullPath` → `/root/root/file.go`, error swallowed
  (`editor_search.go:375-380`, `project_search.go:165`, `workspace.go:350-354`).
- Save never calls `MarkSaved()` — dirty dot never clears after a successful save
  (`editor.go:796-829`).
- Save errors are invisible (`StatusMsg` has no render consumer); toast only on success —
  disk-full looks like a successful save (`editor.go:809-815`, `app.go:805`).
- CRLF silently converted to LF on save (`editor.go:805`).
- Workspace Replace All ignores open buffers → next save silently reverts it; no confirmation
  (`editor_search.go:269-302`).

**Settings / modals**
- "Scan System PATH for Agents" mutates range copies — no-op (`settings_screen.go:975-984`).
- Provider profiles: `GetProviderProfiles` returns the live slice; UI mutates it unlocked while
  fetch/save goroutines race the same data (`settings_screen.go:516-886`, RakitKode
  `provider.go:356-359`).
- "Force Compact Conversation Context" silently deletes history (first + last 3 kept, no
  confirmation, not persisted until next save) (`quota_modal.go:259-271`).
- Lifecycle Hooks & Custom Slash Commands are never persisted nor executed — UI-only
  (`settings_integrations.go:1172,905`).
- `AutoSave` read nowhere; `DefaultShell` only changes a label (`settings_screen.go:1013`,
  `terminal_view.go:157-158`).
- SSH connect: cancel loses to the goroutine (still saves + switches workspace); no guard
  against concurrent connects; failed port parse silently ignored (`ssh_modal.go:237-272,216-222`).
- SSH shell command unquoted (`cd %s && exec $SHELL` with raw path, breaks on spaces,
  `ssh_modal.go:315`); saved-host "SFTP" button targets the wrong host's session.
- Quota modal shows wrong numbers: exhausted quota (≤0% remaining) renders 100% green;
  context gauge labeled "1,000,000 budget" but computed against hidden 200k; quota always
  fetched for hardcoded `"agent-agy"` (`quota_modal.go:52-61,216,233`, `app.go:731`).
- Quota fallback data fabricated as real: "Go Plan", "active", "17 days", hardcoded user
  `lutfi-haslab` (`core/quota/quota.go:104-211`).

**Automation / board**
- Cron automations never fire: `StartScheduler`/`BeginFire`/`ClaimFire` have zero callers;
  only "Run Now" works (`core/automations/automations.go:303,260,275`).
- Board watcher never started — external/agent edits to `board_tasks.json` appear only after
  manual interaction (`core/board/watcher.go` has no callers; AGENTS.md's
  `internal/board/watcher.go` reference is stale).

**Terminal**
- Concurrent `ExecContext` on one session corrupts the marker protocol → spurious timeout →
  session killed mid-command (`core/terminal/manager.go:162-228`).
- Exec-timeout restart replaces an SSH session with a local shell under the same ID
  (`manager.go:217`).
- `Stop` kills only the direct child PID, not the process group — dev servers/watchers orphaned
  (`manager.go:253-255`); engine `ShellMgr` has no `StopAll` caller; agent PTYs never closed at
  exit (`main.go:72-76`).

## Systemic patterns (fix once, eliminate dozens)

1. **Thread discipline.** Mutexes exist on managers but the UI reads fields directly; background
   goroutines write UI fields directly. ~40 sites. Fix: locked snapshot accessors on
   GitManager/AgentState/WorkspaceState + a single UI-thread hop (Window.Update/Invalidate
   pattern) for goroutine results; never touch `AppUI` fields from goroutines.
2. **Error swallowing.** `_ =` on every finish-the-interaction path + unconditional success
   toasts. Fix: propagate to toast via the UI thread; gate success toasts on err == nil.
3. **Render-thread blocking.** Git ops, repo walks, prefs I/O run inside `View()`. Fix: run in
   goroutines + invalidate; cache results.
4. **Feature honesty.** ≥10 UI affordances are mockups/dead (Hooks, Commands, Browser,
   Computer Use, Indexing, AutoSave, DefaultShell, Verify, File History, Outgoing Calls,
   terminal tabs, upload path, model picker modal). Fix: wire or remove — they erode trust.
5. **Frame-bound API misuse.** `AddToast` from goroutines no-ops; `Close()` never wired;
   AfterFunc debounce correct here but the pattern needs one documented helper.
6. **Token convention.** 36 violations, all in `agent_blocks.go` (+2 image viewer, +1 modal) —
   give board-status/accent-badge colors semantic tokens so they adapt across the 11 theme
   variants.

## Verified-clean areas

- Build/vet/gofmt/tests baseline clean (except the race above); zero TODO/FIXME anywhere.
- `core/**` isolation rule holds for Go imports (no `app/**`, no GUI libs). Caveat:
  `core/browseruse/inapp_darwin.go` embeds WKWebView via cgo — spirit-of-the-rule violation.
- Terminal core (UTF-8 reassembly, bounded buffers, idempotent close), fuzzy matcher, prefs
  validation, database/dbviewer (real read-only enforcement), snippets persistence, shortcut
  exact-modifier matching, sidebar/drawer/resize clamp math, explorer cache invalidation —
  all verified sound.
- Agent chat wiring is structurally solid: submit/steer/cancel/checkpoint/approvals reach real
  backends with per-session scoping and persistence.

## Recommended fix order

1. **P0 cluster** (crash, secrets, data loss): nil-modal crash, dirty-buffer prompts, host-key
   verification, 0600/keychain secrets, board write guard, GitManager accessors.
2. **Race sweep** (pattern 1) — removes the flaky tests, wrong-repo and torn-state bugs.
3. **Freeze sweep** (pattern 3) + git parser space fix + automation scheduler wiring.
4. **Editor persistence** (MarkSaved, atomic writes, CRLF, Replace-All vs buffers, error
   surfacing) and **navigation double-prefix** fix.
5. **Honesty pass** (pattern 4): wire or remove fake features.
6. Token-convention cleanup + P3 polish.
