# Install dependencies and run dev (Wails v2 desktop app)

Repo: Go backend (Wails v2) + React/Vite frontend (`frontend/`, package manager: Bun).

## Steps

1. **Preflight toolchain check** (read-only): verify `go`, `bun`, and the Wails CLI are on PATH (`go version`, `bun --version`, `wails version`). If the Wails CLI is missing, install it with `go install github.com/wailsapp/wails/v2/cmd/wails@latest`.

2. **Install frontend dependencies**: `cd frontend && bun install`. (`node_modules/` already exists, so this is fast/idempotent; it also matches `wails.json`'s configured install command.)

3. **Install Go dependencies**: `go mod download` from the repo root.

4. **Fix stale `replace` directive if needed**: `go.mod:48` contains `replace github.com/hasdev/forge-ade => /Users/hy4-mac-002/hasdev/personal/forge-ade`, pointing at a path from a different machine (`hy4-mac-002`). If step 3 or the dev run fails because of it, remove that line and retry. (It will very likely need removal since the target path won't exist on this machine.)

5. **Run dev**: start `wails dev` (equivalent to `make dev`) from the repo root in the background. Verify:
   - Vite dev server comes up at http://127.0.0.1:5173
   - Go backend compiles and the Wails dev app launches without errors
   - Report the dev server URL and any startup log issues; leave the dev process running.

## Notes
- No env files are needed (none exist in the repo).
- `frontend/package-lock.json` is a stale leftover from npm; leaving it untouched since Bun (`bun.lock`) is the manager in use.
